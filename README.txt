ฝึกเขียนฮิรางานะ (ชุดแอพออฟไลน์)
================================

ไฟล์ในโฟลเดอร์นี้
- index.html            ตัวแอพ (ฝังข้อมูลลำดับเส้นและฟอนต์ไว้ในไฟล์เดียว)
- manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอพ
- sw.js                 ทำให้แอพใช้ออฟไลน์ได้หลังเปิดครั้งแรก
- icon-*.png, apple-touch-icon.png  ไอคอนแอพ
- LICENSES.txt          เครดิตและสัญญาอนุญาต

วิธีที่ 1: ติดตั้งเป็นแอพบนหน้าจอหลัก (แนะนำ)
1. นำโฟลเดอร์นี้ไปวางบนเว็บโฮสติ้งที่เป็น https เช่น GitHub Pages, Netlify หรือ Cloudflare Pages
   (ต้องให้ index.html อยู่ที่รากของเว็บ)
2. เปิดลิงก์บนมือถือหนึ่งครั้งขณะออนไลน์ เพื่อให้แอพจดจำไฟล์ไว้
3. iPhone: Safari > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
   Android: Chrome > เมนู ⋮ > ติดตั้งแอพ หรือ เพิ่มลงในหน้าจอหลัก
4. จากนั้นเปิดจากไอคอนได้เลย แม้ไม่มีอินเทอร์เน็ต

วิธีที่ 2: เปิดไฟล์ตรงๆ
เปิด index.html ด้วยเบราว์เซอร์บนคอมพิวเตอร์หรือ Android ได้เลย ไม่ต้องใช้เน็ต
(วิธีนี้ไม่ได้เป็นแอพติดตั้ง และบนมือถือบางรุ่น โดยเฉพาะ iPhone เปิดไฟล์ HTML ในเครื่องได้ยาก)

หมายเหตุ
- ความคืบหน้า (ตัวที่เขียนได้แล้ว) เก็บไว้ในเบราว์เซอร์ของเครื่องนั้น ไม่ซิงก์ข้ามเครื่อง
- ถ้าแก้ไขไฟล์ภายหลัง ให้เปลี่ยนเลข CACHE ใน sw.js (เช่น hiragana-v2) เพื่อให้มือถืออัปเดต
